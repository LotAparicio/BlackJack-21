BlackJack-21 · Gestión de Avisos Institucionales

Entorno de prueba controlado (RN-04 / RNF-06): Operación con datos simulados sin almacenar datos personales reales de alumnos. El almacenamiento local en este visor HTML se guarda en el navegador (localStorage) y la versión completa del sistema corre con Flask + SQLite.

RF-01 · RF-02 · RF-05 · RF-07

Advertencia de anticipación (RF-02 / RN-02): La fecha del evento o límite tiene menos de 3 días de anticipación respecto a hoy.

Vista previa estandarizada del texto (RF-05)

Completa los campos del formulario para visualizar el texto estandarizado con fecha, lugar y enlace.

2. Bandeja de Revisión Editorial y Aprobación

RF-03 · RF-04 · RN-01 · RN-03

Revisa los avisos pendientes, edita el texto si es necesario para cuidar la imagen institucional, aprueba para programar o rechaza indicando un motivo obligatorio.
